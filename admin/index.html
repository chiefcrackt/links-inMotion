Sign in with your GitHub key

Changes save straight to your GitHub repo and show on your page about a minute later. The key stays on this device only.

How to make a key (once per device)
  1. Open GitHub → new fine-grained token.
  2. Name it "T.im editor". Pick an expiration (1 year is fine).
  3. Repository access: Only select repositories → links-inMotion.
  4. Permissions → Repository → Contents: Read and write. Leave everything else alone.
  5. Generate, copy it, and paste it above.
